# Budget Portal Templates

These templates help you publish a budget transparency portal for your LGU quickly. All templates are open source. For the full walkthrough, see [How to Start Your Budget Transparency Portal](BUDGET_GUIDE.md).

---

## Available Templates

| Template                      | Stack              | Repository                                                      | Description                                                                                                        |
|-------------------------------|--------------------|-----------------------------------------------------------------|--------------------------------------------------------------------------------------------------------------------|
| BetterGov.ph Transparency Portal | React + TypeScript | [GitHub](https://github.com/bettergovph/transparency-portal) | Official template. FY 2027 projects and 2020–2026 enacted budgets for one LGU or DPWH office, from the BetterGov.ph Budget API |

---

## Contributing a Template

If you have built a reusable budget portal template that others can fork:

1. Make sure your repository is public, and its `README.md` explains setup and deployment.
2. Make sure it reads from the [BetterGov.ph Budget API](https://budget.bettergov.ph/docs) and keeps the rules in [Keep the Numbers Honest](BUDGET_GUIDE.md#keep-the-numbers-honest).
3. Add a row to the table above.
4. Open a PR with the title: `Add budget template — [Template Name]`

A fork configured for one LGU isn't a template. Register it in the [Budget Portal Directory](https://lgu.bettergov.ph/BUDGET) instead.
