I build and maintain [Better Ocampo](https://www.betterocampo.org), an independent community guide for the Municipality of Ocampo, Camarines Sur. It is a React and TypeScript site for service guides, government records, and contact details that can be checked against a public source or confirmed with the LGU. A fee, schedule, or hotline stays off the page until it can be checked.

## How I can help

Reach out if you want to collaborate on Better Ocampo. That can be a content correction, a new guide, a code review, or a feature for the site. I can also help you find where a page lives: the markdown guides, the category lists, or the companion JSON that fills official names.

## Reaching out

GitHub is the channel I check. Open an issue or pull request on the [Better Ocampo repository](https://github.com/ejsinfuego/betterocampo). Use that for a wrong fact, a missing public source, or a code change.

## Not a fit for

- **Municipal transactions.** I am a volunteer, not part of the municipal government, so I can't process a permit, a complaint, or an office request. For guides and the contact details that have already been checked, use [Better Ocampo](https://www.betterocampo.org). For a transaction, contact the LGU directly.
- **Unsourced local facts.** I won't publish a fee, collection day, or hotline that cannot be tied to a public source or confirmed with the LGU.
- **Paid work and sales pitches.**
