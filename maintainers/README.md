# Maintainer Profiles

Every LGU and budget portal in this directory is built and run by its own volunteers, listed in the **Maintainer/s** column of [`README.md`](../README.md) and [`BUDGET.md`](../BUDGET.md). The people below are some of those portal Maintainers. Each one added their own Maintainer Profile, which says how to reach them, what they're open to, and what they're not a fit for. **Being listed here means they want to be contacted** about the portals they maintain. These are not the Directory Maintainers who run this repository.

Read a profile before you reach out, and follow the [Code of Conduct](../CODE_OF_CONDUCT.md#contacting-maintainers). The website shows the same profiles at [lgu.bettergov.ph/maintainers](https://lgu.bettergov.ph/maintainers/), along with the portals each person maintains.

## Add yourself

You can publish a Maintainer Profile if your GitHub handle is in the Maintainer/s column of an LGU in [`README.md`](../README.md) or a budget portal in [`BUDGET.md`](../BUDGET.md). Read the [privacy notice](../PRIVACY.md) first. Everything in your profile is public.

1. Copy [`_template.md`](_template.md) to `maintainers/<your-github-handle>.md`. The filename is how the directory knows the profile is yours.
2. Fill in what you want to share and delete the rest. Every field is optional.
3. Add yourself to the list above, in alphabetical order by handle:

   ```markdown
   - [Your Name](your-github-handle.md) · @your-github-handle
   ```

4. Open a pull request from your own GitHub account. Nobody else can publish a profile for you.

If you maintain more than one portal, one profile covers all of them. If you rename your GitHub account, rename your profile file and update your Maintainer/s cell in the same pull request.

## Remove yourself

Delete your profile file and your bullet above in a pull request, or ask a Directory Maintainer to do it. To ask privately, email jan@jmacj.dev. Your profile then comes off the website and out of the current repository, but git history and forks may still keep copies. See the [privacy notice](../PRIVACY.md).
